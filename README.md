# MaTouch E32S3RGB40 — Arduino IDE 2 + SquareLine + LVGL 9.5

Plantilla para **ESP32-S3-WROOM-1 N16R8**, pantalla **ST7701S RGB 480×480** y controlador táctil **GT911**.

Utiliza el driver RGB nativo `esp_lcd` de Arduino-ESP32 3.x; no depende de Arduino_GFX, LovyanGFX ni de APIs LVGL 8.


## Arduino IDE 2

Selecciona **ESP32S3 Dev Module** y configura:

- **USB CDC On Boot:** Enabled
- **Flash Size:** 16MB (128Mb)
- **Partition Scheme:** 16M Flash (3MB APP/9.9MB FATFS), o cualquier partición APP ≥ 2MB
- **PSRAM:** OPI PSRAM
- **Upload Mode:** UART0 / Hardware CDC

Instala **LVGL 9.5.0** desde Library Manager.

Abre:

`MaTouch_SquareLine_Template.ino`

Selecciona el puerto y pulsa **Upload**.


## SquareLine

Crea el proyecto con la siguiente configuración:

- **LVGL:** 9.5
- **Language:** C
- **Resolution:** 480×480
- **Color depth:** 16-bit

Exporta únicamente los archivos de la interfaz directamente en:

`src/ui`

La lógica permanente debe permanecer en:

`src/app`

fuera de la carpeta regenerada por SquareLine.

La plantilla acepta tanto `lvgl.h` como `lvgl/lvgl.h` en la configuración de SquareLine.

Para empezar un proyecto SquareLine diferente:

1. Elimina los archivos generados anteriormente de `src/ui`.
2. Conserva `src/ui/lvgl/lvgl.h`.
3. Utiliza **Export UI Files** (no **Template Project**).
4. Selecciona `src/ui` como destino.
5. No elimines las carpetas hermanas `src/app` ni `src/board`.

Las acciones visuales configuradas directamente en SquareLine funcionan sin necesidad de editar código.

Solo es necesario programar `src/app/app_ui.cpp` cuando la interfaz necesite interactuar con hardware, Wi-Fi, sensores, JSON u otra lógica propia.


## Esquema del flujo

```text
SquareLine Studio
       ↓
   Export UI
       ↓
     src/ui
       ↓
Arduino IDE 2
       ↓
     Upload
       ↓
MaTouch ESP32-S3
```


## Arquitectura

```text
MaTouch_SquareLine_Template/
├── MaTouch_SquareLine_Template.ino
└── src/
    ├── board/   → ST7701S + GT911 + LVGL display/input
    ├── ui/      → generated by SquareLine
    └── app/     → permanent application logic
```
